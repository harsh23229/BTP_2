# Updated substitution pipeline — protein, carbohydrates, calories and fat

This bundle replaces the existing Python modules in `BTP_2/substitution/`.
It extends the current retrieval/ranking architecture; it does not introduce a
second substitution pipeline.

## Important nutrient-source decision

`ingredient_nutrients_final.csv` contains:
- 251 rows with `source=usda`, `tier=trusted` (explicit mappings from the
  manually curated `USDA_MAP` in EDA 06);
- 514 rows with `source=recipedb_unverified`, `tier=uncertain`.

The 78 entries that are USDA-trusted in `ingredient_nutrients_final.csv` but
uncertain in `ingredient_per100g_with_tiers.csv` are NOT automatically mapping
errors. The latter file evaluates RecipeDB-derived per-100g values against
USDA nutrient vectors. It is a diagnostic of RecipeDB-derived values, not an
independent authority for rejecting a manually selected USDA mapping.
Similarly, `reverse_match_review.csv` reverse-matches RecipeDB nutrient vectors
to USDA nutrient vectors; it does not verify the selected USDA_MAP entry.

The updated `build_master.py` therefore:
- accepts only rows explicitly marked `source=usda` and `tier=trusted`;
- requires all four nutrient values to be finite and nonnegative;
- checks protein + carbohydrate + fat <= 100.5 g/100 g and kcal in [0, 950];
- requires a non-empty USDA description that exists in the installed USDA
  food taxonomy files;
- leaves RecipeDB comparison differences visible in
  `outputs/nutrient_source_review.csv` without using them to override USDA trust.

This validates the nutrient record and description existence. It does not
replace human review of whether every manually chosen USDA food description
is semantically the best match for the ingredient. Review the USDA_MAP entries
in `EDA/eda_06_nutrient_audit.ipynb` for high-impact ambiguous ingredient names.

## FlavorDB molecular similarity integration

The pipeline reads the precomputed IDF-weighted Jaccard score from:
- `EDA/results/flavour/molecular_similarity.csv`
- `EDA/results/flavour/molecule_audit_entity_stats.csv`

Both files are generated by `EDA/eda_03_flavour.ipynb`. Ingredient names are
matched by normalized exact name; no fuzzy name matches are silently accepted.
A missing pair is assigned `0.0` only when both ingredients have usable,
non-small FlavorDB profiles. Missing/unmapped profiles remain `NaN`. Identical
profiles retain their score and are flagged for cautious interpretation.

The FlavorDB score is one retrieval signal alongside context and optional
embedding evidence. It is not a hard filter and does not establish that two
foods are valid substitutes.

## Run order

Run commands from `BTP_2/substitution/`:

```bash
python build_master.py
python evaluate.py
```

Optional retrieval evaluation:

```bash
python gold_eval.py
```

Interactive use:

```bash
python cook.py
```

Direct examples:

```bash
# Tofu – less fat (tested with Tofu Colombo)
python substitute.py --ingredient tofu --objective less_fat

# Butter – less fat (tested with Walnut Brownie Bites)
python substitute.py --ingredient butter --objective less_fat
```

## Objectives and thresholds

- `more_protein`: at least +3 g protein / 100 g; carbohydrate increase <= 2 g.
- `less_carbs`: at least 3 g fewer carbs / 100 g; protein decrease <= 2 g.
- `less_calories`: at least 10 kcal fewer / 100 g; protein decrease <= 2 g.
- `less_fat`: at least 1 g less fat / 100 g; protein decrease <= 2 g.
- `plant_swap`: existing equal-protein plant-protein objective, retained.

The calorie and fat thresholds are initial operational settings and can be
adjusted after examining candidate coverage and domain requirements.

- `outputs/gold_summary.txt`

## Safety checks

- Candidates are restricted to trusted profiles with finite protein, carbs,
  fat and kcal values.
- Missing target or guard nutrient values are rejected, not allowed through
  comparisons with NaN.
- Hard nutritional filters run before similarity/compatibility ranking.
- `evaluate.py` independently re-checks all returned candidates and raises an
  assertion if any hard-constraint violation is found.

## Requirements and limitations

Install the packages already used by the project (at minimum pandas, numpy,
scipy; plus the packages needed for optional embeddings).

The full build/evaluation cannot be validated without the local graph files,
compressed RecipeDB file, USDA SR/Foundation CSV directories and optional
embedding files. This bundle has been syntax-checked and the ranking logic has
been tested with synthetic cases, including missing nutrient rejection.
